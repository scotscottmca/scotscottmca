A quick PowerShell helper that takes a ConfigMgr or Intune error code and returns
a human-readable meaning, sourced from a JSON list of known codes.

It grew out of the "ConfigMgr and Intune error codes" blog post — instead of
manually digging through logs and lookup tables, this lets you resolve a code
straight from the terminal.
